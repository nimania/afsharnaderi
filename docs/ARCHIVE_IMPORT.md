# Archive import process

A bounded one-time import runs on the GitHub Actions runner. On first deployment it downloads same-origin public HTML, PDFs and images into the repository's `site/` tree, preserving legacy paths for future domain migration and generating redesigned article wrappers. It records original SHA-256 checksums under `site/IMPORT_MANIFEST.json`. The importer does not re-run if that manifest exists. The workflow commits the files to the repository for independent long-term preservation. Initial public sources are `/tabaar/tabaar1.html`, `/docs/kashkoul.html`, `/docs/shajareh.pdf`, `/docs/ismail_memo.pdf`, `/ismail/ismail.html`, `/davoud2/davoudm2.html`, `/drghan/drghan.html` and `/drnader/drnader.html`. All same-origin linked pages and allowed assets are followed within conservative limits. Content should be reviewed for sensitive information about living relatives before production-domain cutover. Historical source bytes are saved under `site/source-original/` for provenance. The root redesigned homepage is never overwritten.

Success criterion: inspect the GitHub workflow logs for `IMPORTED ...` and confirm the resulting import commit and local URLs. This is archival migration, not editorial verification of historical assertions.
