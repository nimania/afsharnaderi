# خاندان افشار نادری — بازسازی وب‌سایت

مخزن بازسازی عمومی آرشیو تاریخی خانوادگی در [afsharnaderi.com](https://afsharnaderi.com/).

**وضعیت: نمونهٔ اولیهٔ آزمایشی، نه نسخهٔ کامل سایت قدیمی.**

## مشاهده

پس از فعال‌سازی GitHub Pages (Settings → Pages → GitHub Actions)، وب‌سایت در نشانی زیر منتشر می‌شود:

https://nimania.github.io/afsharnaderi/

ساختار فایل‌ها:
- `site/`: وب‌سایت استاتیک فارسی، سازگار با موبایل
- `site/archive.html`: آرشیو قابل جست‌وجو و دسته‌بندی
- `site/family.html`: شاخه‌های خاندان با لینک به شجره‌نامهٔ اصلی
- `site/about.html`: دربارهٔ گردآوری و اصول بازسازی
- `.github/workflows/pages.yml`: انتشار خودکار پس از تغییرات شاخهٔ main
- `docs/MIGRATION.md`: چک‌لیست انتقال امن

**در نسخهٔ فعلی فایل‌های اصلی سایت قدیمی هنوز کپی نشده‌اند؛ لینک‌های آن‌ها به سایت قبلی ارجاع می‌دهد.** دامنهٔ اصلی و تنظیمات DNS تغییر نکرده است.

## حریم خصوصی

این مخزن **Public** است. هیچ اسکن حاوی اطلاعات شخصی افراد زنده، نسخهٔ پشتیبان محرمانه یا اطلاعات تماس خصوصی را بدون بررسی و مجوز مناسب به آن اضافه نکنید. محیط آزمایشی از متای `noindex` استفاده می‌کند تا محتوای ناقص برای نمایه‌سازی معرفی نشود.
